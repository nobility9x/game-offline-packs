# game-offline-packs

Kho phát hành game pack cho app **Game Offline 461** (`vn.bhv.gameoffline`).

- `catalog.json` — danh mục pack mới nhất (app đọc file này qua raw URL để tự kiểm tra cập nhật):
  https://raw.githubusercontent.com/nobility9x/game-offline-packs/main/catalog.json
- Các file pack `.zip` nằm ở **Releases** (mỗi pack 1 asset, tải trực tiếp, không giới hạn dung lượng từng file).

Định dạng pack + quy trình phát hành: xem repo dự án app (PACK-FORMAT.md / README.md).
